# LAN Transfer

[![CI](https://github.com/snakex21/LAN-Transfer/actions/workflows/ci.yml/badge.svg)](https://github.com/snakex21/LAN-Transfer/actions/workflows/ci.yml) [![Release](https://img.shields.io/github/v/release/snakex21/LAN-Transfer)](https://github.com/snakex21/LAN-Transfer/releases/latest) [![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](../LICENSE) [![Go](https://img.shields.io/badge/Go-1.23%2B-00ADD8?logo=go)](../go.mod) [![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D6)](#завантаження-та-запуск)

Невелика портативна утиліта для надсилання файлів і папок безпосередньо між двома комп'ютерами в одній локальній мережі. Без хмари, без облікового запису та без сервера-ретранслятора: дані йдуть напряму з одного ПК на інший через зашифроване з'єднання. Ядро на Go, вікно на WebView2 і консольна версія для скриптів.

![Головне вікно LAN Transfer: одержувач, з яким створено пару, і три елементи, готові до надсилання](../docs/screenshots/main.png)

## Можливості

- Автоматичне виявлення інших комп'ютерів, на яких запущено LAN Transfer (широкомовна розсилка UDP, а як резервний варіант — сканування підмережі /24 з обмеженням швидкості).
- Створення пари за допомогою 6-значного коду, який відображається на одержувачі. Без створення пари нічого не можна надіслати й не можна переглядати папки.
- Шифрування TLS 1.3. Під час кожного запуску створюється новий самопідписаний сертифікат; його відбиток закріплюється під час створення пари й перевіряється під час кожного з'єднання.
- Файли й цілі папки зі збереженням структури папок; до 4 файлів надсилаються паралельно.
- Відновлення перерваних передавань і перевірка SHA-256 для кожного файлу.
- Незавершені дані зберігаються в прихованій папці `.lantransfer-partial`, тому обрізаний файл ніколи не з'являється під своєю остаточною назвою.
- У разі збігу назв створюються `file (1).txt` або `Folder (1)`; наявні файли ніколи не перезаписуються.
- Небезпечні назви відхиляються (`..`, абсолютні шляхи, альтернативні потоки даних `file:stream`, зарезервовані назви, як-от `CON`, `NUL`, `COM1`). Перед отриманням перевіряється вільне місце на диску.
- Перетягування з Провідника, черга з прогресом для кожного файлу, швидкістю, рештою часу, скасуванням, відновленням та історією надісланих і отриманих елементів.
- Портативність: один EXE-файл, налаштування та історія зберігаються в папці `data` поруч із ним.

Інтерфейс користувача наразі доступний лише польською мовою.

## Завантаження та запуск

1. Завантажте `LANTransfer-2.0.0-windows-amd64.zip` зі сторінки [Releases](https://github.com/snakex21/LAN-Transfer/releases/latest) і звірте його з опублікованим файлом `.sha256`.
2. Розпакуйте архів у будь-яку папку на обох комп'ютерах.
3. Запустіть `LANTransfer.exe`. Під час першого запуску Windows попросить (UAC) дозвіл на додавання двох правил брандмауера; див. [Порти та брандмауер](#порти-та-брандмауер).

Вимоги: Windows 10 або 11 (64-розрядна) із середовищем виконання WebView2, яке входить до складу сучасних версій Windows. На обох комп'ютерах має працювати версія 2. Версія 2 не може взаємодіяти з версією 1.

## Як створити пару

1. Запустіть LAN Transfer на обох комп'ютерах. Одержувач показує свій код створення пари та відбиток сертифіката у верхньому правому куті.
2. На комп'ютері-відправнику клацніть одержувача в списку **Odbiorca** (Одержувач). Якщо його там немає, скористайтеся **Połącz ręcznie** (Під'єднатися вручну) і введіть його IP-адресу.
3. Введіть 6-значний код з екрана одержувача та порівняйте відбиток сертифіката, показаний у діалоговому вікні, з відбитком на одержувачі. Якщо вони відрізняються, не продовжуйте.
4. Натисніть **Sparuj** (Створити пару). Тепер пристрій позначено як **sparowano** (пару створено).

Після 5 неправильних кодів з одного комп'ютера одержувач блокує подальші спроби з нього. **Nowy kod** (Новий код) створює новий код і скасовує всі наявні пари. Одержувач створює новий код і сертифікат під час кожного запуску, тому після перезапуску одержувача створіть пару знову.

## Надсилання файлів

1. Створіть пару з одержувачем.
2. Перетягніть файли або папки у вікно, скористайтеся **Wybierz pliki** / **Wybierz folder** (Вибрати файли / Вибрати папку) або вставте шлях.
3. Виберіть місце призначення: стандартну папку одержувача (`Downloads\LAN Transfer`) або іншу наявну папку на одержувачі.
4. Натисніть **Wyślij** (Надіслати). Для кожного елемента відображаються прогрес, швидкість і решта часу, і його можна скасувати. Скасоване або перерване передавання можна відновити; надсилається лише відсутня частина.

## Командний рядок

`LANTransferCLI.exe` — та сама програма без вікна, призначена для скриптів і автоматизації.

```powershell
LANTransferCLI.exe serve                          # receive; prints the pairing code
LANTransferCLI.exe devices                        # list devices (JSON)
LANTransferCLI.exe send file.zip folder --to 192.168.0.15 --code 123456 [--dest D:\Inbox] [--parallel 4] [--json]
LANTransferCLI.exe version
```

Код також можна передати у змінній `LANTRANSFER_CODE`. Одержувач без вікна може використовувати фіксований код із `LANTRANSFER_PIN`. Повторний запуск тієї самої команди `send` відновлює перерване передавання.

## Порти та брандмауер

- UDP 45454: виявлення. TCP 45455: передавання (HTTPS).
- Під час першого запуску програма один раз просить (UAC) додати два правила для вхідних підключень: `LAN Transfer 2 Discovery (UDP)` і `LAN Transfer 2 Transfer (TCP)`.
- Правила приймають підключення лише з локальної підмережі (`remoteip=LocalSubnet`) і лише в приватному та доменному мережевих профілях (`profile=private,domain`). У мережі, яку Windows позначає як загальнодоступну (кафе, готель, аеропорт), інші комп'ютери не можуть під'єднатися до LAN Transfer.
- Якщо одержувача не видно у вашій домашній мережі, перевірте в мережевих параметрах Windows, що для цієї мережі вибрано приватний профіль.
- Версія 1 створювала правила з назвами `LAN Transfer Discovery` і `LAN Transfer Transfer` для всіх профілів, зокрема загальнодоступного. Якщо версія 2 їх знайде, вона покаже банер із пропозицією замінити їх. Нічого не змінюється, доки ви не натиснете **Zaktualizuj reguły** (Оновити правила) і не підтвердите запит Windows.

## Примітки щодо безпеки

- Виявлення через UDP не автентифікується; це лише підказка. Довіра забезпечується створенням пари: кодом разом із закріпленим відбитком сертифіката.
- Під час першого створення пари активний зловмисник у тій самій мережі (атака «людина посередині») може видати себе за одержувача. Перед створенням пари порівняйте відбиток сертифіката на обох екранах.
- Відправник, з яким створено пару, може переглядати папки одержувача та зберігати файли в будь-яку наявну там папку (параметр власного місця призначення). Створюйте пари лише з комп'ютерами, яким довіряєте, і використовуйте **Nowy kod**, щоб відкликати всі пари.
- Правила брандмауера не відкривають порти в мережах, позначених як загальнодоступні.

## Змінні середовища

Вони призначені для тестів і автоматизації; для звичайного використання жодна з них не потрібна.

| Змінна | Призначення |
|---|---|
| `LANTRANSFER_PORT`, `LANTRANSFER_UDP_PORT` | інші порти |
| `LANTRANSFER_RECEIVE_DIR`, `LANTRANSFER_DATA_DIR` | папка для отримання, папка даних програми |
| `LANTRANSFER_NAME` | назва комп'ютера, яку бачать інші |
| `LANTRANSFER_LOOPBACK=1` | лише 127.0.0.1: без широкомовних розсилок, без сканування LAN, без правил брандмауера |
| `LANTRANSFER_PEER_UDP_PORTS` | UDP-порти інших екземплярів у режимі loopback |
| `LANTRANSFER_NO_FIREWALL=1` | не створювати й не перевіряти правила брандмауера |
| `LANTRANSFER_PIN`, `LANTRANSFER_CODE` | фіксований код одержувача, код, який використовує відправник |

## Збирання та тести

Go 1.23 або новіша версія у Windows 10/11.

```powershell
build.bat
go test ./...
```

`build.bat` запускає тести та збирає `LANTransfer.exe` (віконна версія) і `LANTransferCLI.exe` (консольна версія) з номером версії з `VERSION` (типово `2.0.0`). Тести охоплюють наскрізні передавання через 127.0.0.1: створення пари та блокування, відхилення неавтентифікованих запитів, файли від 0 Б до 96 МБ, папки з назвами в Unicode та шляхи довші за 260 символів, конфлікти назв, шкідливі назви, неправильну контрольну суму, скасування та відновлення, заповнений диск і закріплення сертифіката.

Примітки до випуску: [docs/releases/v2.0.0.md](../docs/releases/v2.0.0.md).
