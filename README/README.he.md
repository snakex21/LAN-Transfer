# LAN Transfer

[![CI](https://github.com/snakex21/LAN-Transfer/actions/workflows/ci.yml/badge.svg)](https://github.com/snakex21/LAN-Transfer/actions/workflows/ci.yml) [![Release](https://img.shields.io/github/v/release/snakex21/LAN-Transfer)](https://github.com/snakex21/LAN-Transfer/releases/latest) [![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](../LICENSE) [![Go](https://img.shields.io/badge/Go-1.23%2B-00ADD8?logo=go)](../go.mod) [![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D6)](#הורדה-והפעלה)

כלי נייד קטן לשליחת קבצים ותיקיות ישירות בין שני מחשבים באותה רשת מקומית. בלי ענן, בלי חשבון ובלי שרת ממסר: הנתונים עוברים ישירות ממחשב אחד לשני דרך חיבור מוצפן. ליבה שנכתבה ב-Go, חלון WebView2 וגרסת שורת פקודה לסקריפטים.

## תכונות

- גילוי אוטומטי של מחשבים אחרים שמריצים את LAN Transfer (שידור UDP, ובנוסף סריקת /24 מוגבלת בקצב כגיבוי).
- צימוד באמצעות קוד בן 6 ספרות שמוצג במחשב המקבל. ללא צימוד אי אפשר לשלוח דבר ואי אפשר לעיין בתיקיות.
- הצפנת TLS 1.3. בכל הפעלה נוצרת תעודה חדשה בחתימה עצמית; טביעת האצבע שלה מוצמדת (pinning) בזמן הצימוד ונבדקת בכל חיבור.
- קבצים ותיקיות שלמות, עם שמירה על מבנה התיקיות ושליחה של עד 4 קבצים במקביל.
- המשך של העברות שנקטעו ובדיקת SHA-256 של כל קובץ.
- נתונים שלא הושלמו נשמרים בתיקייה מוסתרת `.lantransfer-partial`, כך שקובץ קטוע לעולם לא מופיע בשמו הסופי.
- התנגשויות שמות הופכות ל-`file (1).txt` או ל-`Folder (1)`; קבצים קיימים לעולם אינם נדרסים.
- שמות מסוכנים נדחים (`..`, נתיבים מוחלטים, זרמי נתונים חלופיים מסוג `file:stream`, שמות שמורים כמו `CON`, `NUL`, `COM1`). שטח הדיסק הפנוי נבדק לפני הקבלה.
- גרירה ושחרור מסייר הקבצים, תור עם התקדמות, מהירות וזמן נותר לכל קובץ, ביטול, המשך והיסטוריה של פריטים שנשלחו והתקבלו.
- נייד: קובץ EXE יחיד, וההגדרות וההיסטוריה נשמרות בתיקייה `data` שלידו.

ממשק המשתמש זמין כרגע בפולנית.

## הורדה והפעלה

1. הורידו את `LANTransfer-2.0.0-windows-amd64.zip` מתוך [Releases](https://github.com/snakex21/LAN-Transfer/releases/latest) ואמתו אותו מול הקובץ `.sha256` שפורסם.
2. חלצו אותו לתיקייה כלשהי בשני המחשבים.
3. הפעילו את `LANTransfer.exe`. בהפעלה הראשונה Windows מבקש (UAC) הרשאה להוסיף שני כללי חומת אש; ראו [פורטים וחומת אש](#פורטים-וחומת-אש).

דרישות: Windows 10 או 11 (64 סיביות) עם סביבת הריצה WebView2, שהיא חלק מגרסאות Windows העדכניות. בשני המחשבים חייבת לרוץ גרסה 2. גרסה 2 אינה יכולה לתקשר עם גרסה 1.

## איך לבצע צימוד

1. הפעילו את LAN Transfer בשני המחשבים. המחשב המקבל מציג את קוד הצימוד ואת טביעת האצבע של התעודה בפינה הימנית העליונה.
2. במחשב השולח, לחצו על המקבל ברשימה **Odbiorca** (מקבל). אם הוא לא מופיע, השתמשו ב-**Połącz ręcznie** (התחברות ידנית) והזינו את כתובת ה-IP שלו.
3. הקלידו את הקוד בן 6 הספרות ממסך המקבל והשוו את טביעת האצבע של התעודה שמוצגת בחלון לזו שמוצגת במקבל. אם הן שונות, אל תמשיכו.
4. לחצו על **Sparuj** (צימוד). כעת המכשיר מציג **sparowano** (מצומד).

לאחר 5 קודים שגויים ממחשב אחד, המקבל חוסם ניסיונות נוספים ממנו. **Nowy kod** (קוד חדש) יוצר קוד חדש ומבטל את כל הצימודים הקיימים. המקבל יוצר קוד ותעודה חדשים בכל הפעלה, ולכן לאחר שהמקבל מופעל מחדש יש לבצע צימוד שוב.

## שליחת קבצים

1. בצעו צימוד עם המקבל.
2. גררו קבצים או תיקיות אל החלון, השתמשו ב-**Wybierz pliki** / **Wybierz folder** (בחירת קבצים / בחירת תיקייה), או הדביקו נתיב.
3. בחרו את היעד: תיקיית ברירת המחדל של המקבל (`Downloads\LAN Transfer`) או תיקייה קיימת אחרת במקבל.
4. לחצו על **Wyślij** (שליחה). כל פריט מציג התקדמות, מהירות וזמן נותר, וניתן לבטל אותו. העברה שבוטלה או נקטעה ניתנת להמשך; רק החלק החסר נשלח.

## שורת הפקודה

`LANTransferCLI.exe` הוא אותה תוכנה ללא חלון, לסקריפטים ולאוטומציה.

```powershell
LANTransferCLI.exe serve                          # receive; prints the pairing code
LANTransferCLI.exe devices                        # list devices (JSON)
LANTransferCLI.exe send file.zip folder --to 192.168.0.15 --code 123456 [--dest D:\Inbox] [--parallel 4] [--json]
LANTransferCLI.exe version
```

אפשר להעביר את הקוד גם דרך `LANTRANSFER_CODE`. מקבל ללא חלון יכול להשתמש בקוד קבוע מתוך `LANTRANSFER_PIN`. הרצה חוזרת של אותה פקודת `send` ממשיכה העברה שנקטעה.

## פורטים וחומת אש

- UDP 45454: גילוי. TCP 45455: העברה (HTTPS).
- בהפעלה הראשונה האפליקציה מבקשת פעם אחת (UAC) להוסיף שני כללי תעבורה נכנסת: `LAN Transfer 2 Discovery (UDP)` ו-`LAN Transfer 2 Transfer (TCP)`.
- הכללים מקבלים חיבורים רק מתת-הרשת המקומית (`remoteip=LocalSubnet`) ורק בפרופילי הרשת "פרטית" ו"תחום" (`profile=private,domain`). ברשת ש-Windows מסמן כ"ציבורית" (בית קפה, מלון, שדה תעופה) מחשבים אחרים אינם יכולים להתחבר ל-LAN Transfer.
- אם המקבל אינו נראה ברשת הביתית שלכם, ודאו שהרשת מוגדרת כ"פרטית" בהגדרות הרשת של Windows.
- גרסה 1 יצרה כללים בשם `LAN Transfer Discovery` ו-`LAN Transfer Transfer` לכל הפרופילים, כולל "ציבורית". אם גרסה 2 מוצאת אותם, היא מציגה באנר שמציע להחליף אותם. שום דבר לא משתנה עד שתלחצו על **Zaktualizuj reguły** (עדכון כללים) ותאשרו את בקשת האישור של Windows.

## הערות אבטחה

- הגילוי דרך UDP אינו מאומת; הוא רק רמז. האמון נובע מהצימוד: הקוד יחד עם טביעת האצבע המוצמדת של התעודה.
- במהלך הצימוד הראשון, תוקף פעיל באותה רשת (אדם בתווך) עלול להתחזות למקבל. השוו את טביעת האצבע של התעודה בשני המסכים לפני הצימוד.
- שולח מצומד יכול לעיין בתיקיות של המקבל ולשמור קבצים בכל תיקייה קיימת בו (אפשרות היעד המותאם). בצעו צימוד רק עם מחשבים שאתם סומכים עליהם, והשתמשו ב-**Nowy kod** כדי לבטל את כל הצימודים.
- כללי חומת האש אינם פותחים את הפורטים ברשתות שמסומנות כ"ציבוריות".

## משתני סביבה

משתנים אלה מיועדים לבדיקות ולאוטומציה; בשימוש רגיל אין צורך באף אחד מהם.

| משתנה | משמעות |
|---|---|
| `LANTRANSFER_PORT`, `LANTRANSFER_UDP_PORT` | פורטים אחרים |
| `LANTRANSFER_RECEIVE_DIR`, `LANTRANSFER_DATA_DIR` | תיקיית קבלה, תיקיית נתוני התוכנה |
| `LANTRANSFER_NAME` | שם המחשב שמוצג לאחרים |
| `LANTRANSFER_LOOPBACK=1` | 127.0.0.1 בלבד: ללא שידורים, ללא סריקת LAN, ללא כללי חומת אש |
| `LANTRANSFER_PEER_UDP_PORTS` | פורטי UDP של מופעים אחרים במצב loopback |
| `LANTRANSFER_NO_FIREWALL=1` | לא ליצור ולא לבדוק כללי חומת אש |
| `LANTRANSFER_PIN`, `LANTRANSFER_CODE` | קוד קבוע של המקבל, הקוד שבו משתמש השולח |

## בנייה ובדיקות

Go 1.23 ומעלה על Windows 10/11.

```powershell
build.bat
go test ./...
```

`build.bat` מריץ את הבדיקות ובונה את `LANTransfer.exe` (חלון) ואת `LANTransferCLI.exe` (מסוף) עם הגרסה מתוך `VERSION` (ברירת מחדל `2.0.0`). הבדיקות כוללות העברות מקצה לקצה דרך 127.0.0.1: צימוד ונעילה, דחיית בקשות לא מאומתות, קבצים מ-0 B עד 96 MB, תיקיות Unicode ונתיבים ארוכים מ-260 תווים, התנגשויות שמות, שמות זדוניים, checksum שגוי, ביטול והמשך, דיסק מלא והצמדת תעודה.

הערות גרסה: [docs/releases/v2.0.0.md](../docs/releases/v2.0.0.md).
