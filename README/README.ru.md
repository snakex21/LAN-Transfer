# LAN Transfer

[![CI](https://github.com/snakex21/LAN-Transfer/actions/workflows/ci.yml/badge.svg)](https://github.com/snakex21/LAN-Transfer/actions/workflows/ci.yml) [![Release](https://img.shields.io/github/v/release/snakex21/LAN-Transfer)](https://github.com/snakex21/LAN-Transfer/releases/latest) [![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](../LICENSE) [![Go](https://img.shields.io/badge/Go-1.23%2B-00ADD8?logo=go)](../go.mod) [![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D6)](#загрузка-и-запуск)

Небольшая портативная утилита для передачи файлов и папок напрямую между двумя компьютерами в одной локальной сети. Без облака, без учётной записи и без сервера-ретранслятора: данные идут напрямую с одного ПК на другой по зашифрованному соединению. Ядро на Go, окно на WebView2 и консольная версия для скриптов.

## Возможности

- Автоматическое обнаружение других компьютеров, на которых запущен LAN Transfer (широковещательная рассылка UDP, а в качестве резервного варианта — сканирование подсети /24 с ограничением скорости).
- Сопряжение с помощью 6-значного кода, который показывается на получателе. Без сопряжения ничего нельзя отправить и нельзя просматривать папки.
- Шифрование TLS 1.3. При каждом запуске создаётся новый самоподписанный сертификат; его отпечаток закрепляется при сопряжении и проверяется при каждом подключении.
- Файлы и целые папки с сохранением структуры папок; до 4 файлов передаются параллельно.
- Возобновление прерванных передач и проверка SHA-256 для каждого файла.
- Незавершённые данные хранятся в скрытой папке `.lantransfer-partial`, поэтому обрезанный файл никогда не появляется под своим окончательным именем.
- При совпадении имён создаются `file (1).txt` или `Folder (1)`; существующие файлы никогда не перезаписываются.
- Опасные имена отклоняются (`..`, абсолютные пути, альтернативные потоки данных `file:stream`, зарезервированные имена, такие как `CON`, `NUL`, `COM1`). Перед приёмом проверяется свободное место на диске.
- Перетаскивание из Проводника, очередь с прогрессом по каждому файлу, скоростью, оставшимся временем, отменой, возобновлением и историей отправленных и полученных элементов.
- Портативность: один EXE-файл, настройки и история хранятся в папке `data` рядом с ним.

Пользовательский интерфейс сейчас доступен только на польском языке.

## Загрузка и запуск

1. Скачайте `LANTransfer-2.0.0-windows-amd64.zip` со страницы [Releases](https://github.com/snakex21/LAN-Transfer/releases/latest) и сверьте его с опубликованным файлом `.sha256`.
2. Распакуйте архив в любую папку на обоих компьютерах.
3. Запустите `LANTransfer.exe`. При первом запуске Windows запросит (UAC) разрешение на добавление двух правил брандмауэра; см. [Порты и брандмауэр](#порты-и-брандмауэр).

Требования: Windows 10 или 11 (64-разрядная) со средой выполнения WebView2, которая входит в состав современных версий Windows. На обоих компьютерах должна работать версия 2. Версия 2 не может взаимодействовать с версией 1.

## Как выполнить сопряжение

1. Запустите LAN Transfer на обоих компьютерах. Получатель показывает свой код сопряжения и отпечаток сертификата в правом верхнем углу.
2. На компьютере-отправителе щёлкните получателя в списке **Odbiorca** (Получатель). Если его там нет, воспользуйтесь кнопкой **Połącz ręcznie** (Подключиться вручную) и введите его IP-адрес.
3. Введите 6-значный код с экрана получателя и сравните отпечаток сертификата, показанный в диалоговом окне, с отпечатком на получателе. Если они различаются, не продолжайте.
4. Нажмите **Sparuj** (Выполнить сопряжение). Теперь устройство отображается как **sparowano** (сопряжено).

После 5 неверных кодов с одного компьютера получатель блокирует дальнейшие попытки с этого компьютера. **Nowy kod** (Новый код) создаёт новый код и отменяет все существующие сопряжения. Получатель создаёт новый код и сертификат при каждом запуске, поэтому после перезапуска получателя выполните сопряжение заново.

## Отправка файлов

1. Выполните сопряжение с получателем.
2. Перетащите файлы или папки в окно, воспользуйтесь **Wybierz pliki** / **Wybierz folder** (Выбрать файлы / Выбрать папку) или вставьте путь.
3. Выберите место назначения: папку получателя по умолчанию (`Downloads\LAN Transfer`) или другую существующую папку на получателе.
4. Нажмите **Wyślij** (Отправить). Для каждого элемента отображаются прогресс, скорость и оставшееся время, и его можно отменить. Отменённую или прерванную передачу можно возобновить; отправляется только недостающая часть.

## Командная строка

`LANTransferCLI.exe` — та же программа без окна, предназначенная для скриптов и автоматизации.

```powershell
LANTransferCLI.exe serve                          # receive; prints the pairing code
LANTransferCLI.exe devices                        # list devices (JSON)
LANTransferCLI.exe send file.zip folder --to 192.168.0.15 --code 123456 [--dest D:\Inbox] [--parallel 4] [--json]
LANTransferCLI.exe version
```

Код также можно передать в переменной `LANTRANSFER_CODE`. Получатель без окна может использовать фиксированный код из `LANTRANSFER_PIN`. Повторный запуск той же команды `send` возобновляет прерванную передачу.

## Порты и брандмауэр

- UDP 45454: обнаружение. TCP 45455: передача (HTTPS).
- При первом запуске приложение один раз запрашивает (UAC) добавление двух правил для входящих подключений: `LAN Transfer 2 Discovery (UDP)` и `LAN Transfer 2 Transfer (TCP)`.
- Правила принимают подключения только из локальной подсети (`remoteip=LocalSubnet`) и только в частном и доменном сетевых профилях (`profile=private,domain`). В сети, которую Windows помечает как общедоступную (кафе, гостиница, аэропорт), другие компьютеры не могут подключиться к LAN Transfer.
- Если получатель не виден в вашей домашней сети, проверьте в сетевых параметрах Windows, что для этой сети выбран частный профиль.
- Версия 1 создавала правила с именами `LAN Transfer Discovery` и `LAN Transfer Transfer` для всех профилей, включая общедоступный. Если версия 2 их обнаружит, она покажет баннер с предложением заменить их. Ничего не изменится, пока вы не нажмёте **Zaktualizuj reguły** (Обновить правила) и не подтвердите запрос Windows.

## Замечания по безопасности

- Обнаружение по UDP не проходит аутентификацию; это лишь подсказка. Доверие обеспечивается сопряжением: кодом вместе с закреплённым отпечатком сертификата.
- Во время первого сопряжения активный злоумышленник в той же сети (атака «человек посередине») может выдать себя за получателя. Перед сопряжением сравните отпечаток сертификата на обоих экранах.
- Сопряжённый отправитель может просматривать папки получателя и сохранять файлы в любую существующую там папку (параметр собственного места назначения). Выполняйте сопряжение только с компьютерами, которым доверяете, и используйте **Nowy kod**, чтобы отозвать все сопряжения.
- Правила брандмауэра не открывают порты в сетях, помеченных как общедоступные.

## Переменные окружения

Они предназначены для тестов и автоматизации; при обычном использовании ни одна из них не нужна.

| Переменная | Назначение |
|---|---|
| `LANTRANSFER_PORT`, `LANTRANSFER_UDP_PORT` | другие порты |
| `LANTRANSFER_RECEIVE_DIR`, `LANTRANSFER_DATA_DIR` | папка для приёма, папка данных программы |
| `LANTRANSFER_NAME` | имя компьютера, которое видят другие |
| `LANTRANSFER_LOOPBACK=1` | только 127.0.0.1: без широковещательных рассылок, без сканирования LAN, без правил брандмауэра |
| `LANTRANSFER_PEER_UDP_PORTS` | UDP-порты других экземпляров в режиме loopback |
| `LANTRANSFER_NO_FIREWALL=1` | не создавать и не проверять правила брандмауэра |
| `LANTRANSFER_PIN`, `LANTRANSFER_CODE` | фиксированный код получателя, код, используемый отправителем |

## Сборка и тесты

Go 1.23 или новее в Windows 10/11.

```powershell
build.bat
go test ./...
```

`build.bat` запускает тесты и собирает `LANTransfer.exe` (оконная версия) и `LANTransferCLI.exe` (консольная версия) с номером версии из `VERSION` (по умолчанию `2.0.0`). Тесты включают сквозные передачи через 127.0.0.1: сопряжение и блокировку, отклонение неаутентифицированных запросов, файлы от 0 Б до 96 МБ, папки с именами в Unicode и пути длиннее 260 символов, конфликты имён, вредоносные имена, неверную контрольную сумму, отмену и возобновление, заполненный диск и закрепление сертификата.

Примечания к выпуску: [docs/releases/v2.0.0.md](../docs/releases/v2.0.0.md).
